# flamegold

> **Unofficial.** This is a personal project. It is not affiliated with or endorsed by any university, law school, or journal whose layout it imitates.

A [Typst](https://typst.app/) template for Traditional Chinese law papers, modeled on the journals of Taiwan's leading law schools: bilingual cover, abstracts, outline, note-style CSL citations, and a bibliography grouped by language and type. A `preset` parameter picks the journal layout to imitate, such as `"ntulj"` (National Taiwan University Law Journal) or `"ntpu"` (Taipei University Law Review); without it, the template uses a generic layout. The name comes from the Taiwan flamegold rain tree.

Requirements, installation, usage, parameters, and examples are documented only in the Chinese README, [README-zh.md](README-zh.md).
